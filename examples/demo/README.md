# Demo Dataset

These spreadsheets represent a simplified real-world retail workflow. They are provided for testing both Stock Processing and Inventory Reconciliation.

*No personal or company-identifiable information is included.*

## Files Included
*   **`cross_check_system_stock.xls`**: Legacy format system snapshot.
*   **`cross_check_physical_count.xlsx`**: Raw barcode scanner outputs.
*   **`shared_cost_list.xlsx`**: Procurement prices.
*   **`shared_sales_price_list.xlsx`**: Public retail prices.
*   **`stock_processing_raw_stock.xlsx`**: Unprocessed multi-branch inventory.
*   **`yoy_sales_history.xlsx`**: Historical sales data for comparative analysis.
